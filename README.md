To get the program to work, you will have to install the following libraries on thonny: customtkinter, pycaw, pynput, psutil, Pillow.
To install these libraries Open Thonny.
Click Tools in the top menu bar and select Manage packages....
Type the library name (e.g., customtkinter) into the search bar and click Search.
Click Install on the matching package.
Repeat steps 3–4 for the remaining libraries:
pycaw
pynput
psutil
Pillow
Close the manager window once all installations finish.
